# X86 Склад Android

Нативная Android-оболочка для https://x86.kz/stock/.

Исходники версии 1.5.0 находятся в модуле `app` в корне репозитория.
ZIP-файлы сохранены как архивные материалы и не используются при сборке.

Включено:
- отдельное приложение без интерфейса браузера;
- постоянная авторизация/cookies;
- камера для сканера штрихкодов/QR;
- загрузка PDF и других файлов в Downloads;
- JavaScript/DOM storage для текущего интерфейса X86 Stock;
- системная кнопка Назад работает по истории приложения;
- обновление страницы жестом вниз.

## Сборка через GitHub Actions

Сборка автоматически запускается при push в `main`. Для ручного запуска:
Actions → Build X86 Stock APK → Run workflow.

Workflow собирает release APK из папки `app`, проверяет его подпись и
сохраняет в Artifacts как `X86-Stock-Release-APK`.
Внутри архива находится `app-release.apk`.

Используются существующие секреты репозитория:
- `X86_KEYSTORE_BASE64` — keystore в Base64;
- `X86_KEYSTORE_PASSWORD` — пароль хранилища и ключа `x86-release`.

Для совместимости с установленным приложением необходимо сохранять тот же
ключ подписи. Workflow не создаёт новый ключ; временный keystore удаляется
после сборки, в том числе при ошибке.

## Локальная сборка

Откройте корень репозитория в Android Studio. Требуются JDK 17,
Gradle 8.9 и Android SDK 35 с Build Tools 35.0.0.

Для отладочной сборки: `gradle :app:assembleDebug`.
Для подписанной release-сборки задайте переменные `X86_KEYSTORE_PATH`
(абсолютный путь к существующему keystore) и `X86_KEYSTORE_PASSWORD`, затем
выполните `gradle :app:assembleRelease --no-daemon`.
Без переменных подписи локальная release-сборка остаётся неподписанной.
Не добавляйте keystore и пароли в Git.
