Как работает оплата
В корзине нажмите «Оплатить через Smart POS». Сумма уйдёт на терминал. Товар списывается со склада только после успешного ответа Smart POS. Способ оплаты определяется по фактическому ответу терминала и используется для расчёта комиссии.
