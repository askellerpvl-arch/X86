# X86 Галерея · Android 0.2

Тестовая локальная версия: сканирование MediaStore, поиск точных дублей SHA-256 и похожих снимков dHash, группировка скриншотов, WhatsApp и приблизительный поиск электроники с ML Kit. Фотографии никуда не выгружаются. Платный API и интернет не нужны. 

Выбор всех фото текущего раздела: открой категорию (например, WhatsApp), нажми «Выбрать все в разделе». Повторное нажатие снимает только выбор этого раздела.\n\nСначала проверь результаты. Ничего автоматически не удаляется; выбранные файлы отправляются в системную корзину по 100 фотографий после подтверждения Android.

Сборка: GitHub Actions → Build X86 Gallery Cleaner APK → Artifacts → X86-GalleryCleaner-debug. Устанавливать APK только для теста. Без резервной копии важных фотографий не удаляй большие группы.
